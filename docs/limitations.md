# Remaining limits after the sprint

- **Live providers:** NVIDIA mission-planning code is connected and schema/policy-tested, but real inference is blocked by an absent key. Nightshift lacks a reachable configured runtime/token/model. Mocked transport tests do not count as live sponsor verification.
- **Bounded tools:** the planner can compose six registered tools, not arbitrary commands. Generated software supports calculators and task/inventory/contact records through reviewed templates. General model-generated project code, package installation and deployment are unsupported.
- **Planning/verification:** model-written criteria and explanations are advisory. Independent acceptance comes from fixed tool contracts, reference calculations and artifact hashes. Schema validation is not a proof that a selected plan fully satisfies every possible natural-language objective. Unsupported requests/inputs must be reviewed; measured tool outputs remain explicitly scoped.
- **Research/data:** supplied-source lexical retrieval, exact metric syntax and complete finite numeric CSV columns. No general semantic contradiction resolution, missing-data modeling, causal diagnosis, external source authentication or live web/SQL federation. Numeric source-to-CSV reconciliation does not establish matching units, scope or factual truth.
- **Experiments/skills:** measured baseline/candidate tests and independent transfer records exist. Small synthetic detector fixtures and bounded software contracts are capability tests, not general scientific benchmarks. Procedures are versioned and reused; no weights are trained.
- **Meterless/Zetaris:** Nightshift follows documented runtime transport. Open Meterless engines were investigated but not imported, rebuilt or conformance-certified. No invented Agent Engine endpoint. Zetaris live connector remains pending verified docs/infrastructure.
- **Hosting:** Vercel/Render configuration and a private demo gate are implemented. No hosting credentials or public service deployment exist in this task. Standard Render web hosting does not supply the local Docker execution daemon needed by software tests. A dedicated authorized Linux execution host is required; no remote runner adapter is claimed.
- **Operations/security:** one API worker, SQLite and local artifact files; no distributed leases, PostgreSQL, cross-process scheduler, transactional artifact filesystem, multi-tenant RBAC, session revocation console or hostile-code execution service. Shared demo authentication is not enterprise identity. Per-mission trusted template tests execute in restricted containers with no host fallback.
- **Visuals:** responsive original 3D interface, real graph focus/hover/status, adaptive initial pixel ratio, capped frames, reduced motion and text fallback. No formal accessibility certification, device-wide GPU benchmark or frame-time-based dynamic quality controller.

The verified local application and pushed commits are the working deliverables. Publication and fresh-task/hosting restoration must be tested separately rather than inferred from a build or saved configuration.
